# Files folder

Place downloadable documents here.

## Resume / CV

1. Add your CV as `cv.pdf` in this folder.
2. In `data/site.json`, set `"cv": "files/cv.pdf"`.

Until you add `cv.pdf`, the site links to this README for reference.

## Publication PDFs

Optional: store paper PDFs under `files/papers/` and link to them from `data/publications.json`:

```json
"links": { "pdf": "files/papers/my-paper.pdf" }
```
